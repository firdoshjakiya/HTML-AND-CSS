# HTML-AND-CSS

It contains simple projects designed using plain HTML and CSS which were also edited afterwards.
GOAL: For strengthening concepts of tables, divs, forms and certain styling patterns.

#Modern Periodic Table:
It displays the modern periodic table with color-coded element groups.

#Forms:
A beginner-friendly HTML and CSS project containing forms with input fields, dropdowns, textarea, and buttons, styled with proper spacing and scaling.

#Student Registration Form:
The Student Registration Form is a simple web-based project developed using HTML and CSS. It is designed to collect and organize basic student information through text fields, dropdown menus, and other form elements. CSS is used to provide proper spacing, alignment, borders, scaling, and a clean layout. This project helps in understanding the basic concepts of HTML forms and CSS styling and is suitable for beginners learning web development.
